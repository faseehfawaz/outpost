Outpost // Threat Intelligence & Automated Takedown

Every phishing kit leaves
a fingerprint. This reads it.

Outpost ingests public threat feeds and a live Certificate Transparency stream, scores every candidate against a UAE-first brand model, pulls down kits attackers leave exposed, clusters them by code similarity, and automatically notifies the registrars and hosts responsible — a full cycle, around the clock.

How It Works

One queue. Six stages. No human in the loop.

Every candidate URL moves through the same state machine — coordinated by a single PostgreSQL table with SELECT FOR UPDATE SKIP LOCKED, no message broker required. This is the actual pipeline topology, not a mockup.

Public feeds → ingest → triage → kit hunter → sandbox → cluster → takedown cycle running
01

Ingestion

Public feeds plus a live Certificate Transparency stream, merged into one queue.

02

Triage

Favicon and logo hashing, DOM signals and hostname patterns score every candidate 0–100.

03

Kit Hunter

Passive probing for kit archives attackers leave exposed on the host.

04

Sandbox

Static deobfuscation, --network none, unpacks the kit and surfaces exfil channels.

05

Clustering

TLSH fuzzy hashing and file-overlap group kits into threat-actor profiles.

06

Takedown

RDAP-enriched abuse notices go out to the registrar or host — automatically.
