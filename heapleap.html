Live Module

Outpost

Threat Intelligence & Automated Takedown Platform

Outpost is a passive threat-intelligence platform built to find active phishing campaigns before they cause more damage. It watches public feeds and live certificate issuance, scores candidates against a UAE-first brand model — Emirates NBD, ADCB, RTA, Etisalat, UAE PASS — pulls down the kits attackers leave exposed, clusters them by code similarity, and automatically notifies the registrars and hosts responsible for taking them offline.

The pipeline · one PostgreSQL state machine, six stages, a full cycle every 14 minutes

01

Ingestion

8 public feeds plus a live Certificate Transparency stream, merged into one queue.

02

Triage

Favicon and logo hashing, DOM signals and hostname patterns score every candidate 0–100.

03

Kit Hunter

Passive probing for kit archives attackers leave exposed on the host.

04

Sandbox

Static deobfuscation unpacks the kit and surfaces attacker exfil channels.

05

Clustering

Fuzzy hashing and file-overlap group kits into threat-actor profiles.

06

Takedown

RDAP-enriched abuse notices go out to the registrar or host — automatically.

How We Operate

A passive-research line we don't cross.

01

Passive research only

Outpost only retrieves what's already served to any visitor over standard HTTP. No brute-forcing, no exploits, no authentication bypass.

02

Victim data protection

Live credentials are never logged, stored, or transmitted. Every exfil channel is hashed or redacted before it touches a database.

03

No attack execution

Kits are dissected in an isolated sandbox. Attacker code is analyzed — never run.
